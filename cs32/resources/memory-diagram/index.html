Guidelines

When drawing memory diagrams for code execution snapshots, follow these visual conventions:

  1. Stack Frames: Each active function call gets its own labeled stack frame box (e.g., main stack frame, process stack frame). Function parameters (such as arrPtr for process()) are drawn inside the stack frame of the function they belong to.
  2. Objects & Struct Variables: Objects and struct variables are represented as boxes containing each of their individual member variables inside (e.g., data, next).
  3. Heap Allocations: Objects created dynamically using new appear in the Heap as unnamed boxes (since dynamic heap allocations do not have variable names).
  4. Pointers & Pointer Relationships: Pointer relationships are represented as arrows originating from inside the pointer's box and pointing directly to the target object, array, or element.
  5. Arrays: Arrays are drawn as contiguous boxes with their index numbers (0, 1, 2) labeled above each element cell.

    int data;
    Node* next;

    Node* myNode = new Node;
    myNode->data = arrPtr[1];
    myNode->next = nullptr;

    int scores[3] = { 95, 88, 72 };
